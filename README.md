# Rafiq AI – Your AI Companion

موقع مساعد ذكي بواجهة عربية RTL (مع الإنجليزية) مبني بـ HTML5 وCSS3 وJavaScript فقط، بدون أي أدوات بناء.

## ⚠️ حالة المشروع الحالية (مهم)

- **المساعد تجريبي محلي**: يرد على أسئلة بسيطة (المهام، عدد الملاحظات، الوقت، التاريخ) بقواعد مكتوبة في `script.js`. **ليس متصلاً بنموذج ذكاء اصطناعي حقيقي** حتى تربطه بنفسك (انظر قسم الربط).
- **الحساب تجريبي**: تسجيل الدخول لا يتحقق من أي شيء ولا تُحفظ كلمة المرور. لا يوجد خادم ولا حسابات حقيقية.
- **الملفات** التي تختارها تبقى في الصفحة فقط، ولا تُرفع إلى أي خادم، وتختفي عند تحديث الصفحة.
- **الاشتراكات** صفحة عرض فقط، ولا يوجد نظام دفع.

## التخزين (LocalStorage) وحدوده

تُحفظ البيانات في متصفحك فقط: المهام، الملاحظات، المحادثات، المفضلة، الإعدادات، الملف الشخصي، ونشاط الأيام.

- **لا مزامنة بين الأجهزة**: بياناتك على هذا الجهاز وهذا المتصفح فقط.
- **لا حسابات حقيقية**: أي شخص يفتح المتصفح نفسه يرى البيانات نفسها.
- **تُحذف** إذا مسحت بيانات المتصفح أو استخدمت وضع التصفح الخفي.
- **حجمها محدود** (حوالي 5MB). صورة الملف الشخصي تُصغَّر تلقائياً لتوفير المساحة.
- **غير مشفّرة**: لا تكتب فيها أسراراً (كلمات مرور، أرقام بنوك).
- الزر **تصدير بياناتي** في الإعدادات ينزّل نسخة JSON احتياطية.

## ربط ذكاء اصطناعي حقيقي

### القاعدة الذهبية
**لا تضع مفتاح API داخل `script.js` أبداً.** أي شخص يفتح الموقع يستطيع قراءة المفتاح ويستخدم رصيدك. الحل الصحيح: **خادم وسيط صغير** يحمل المفتاح، والموقع يكلّم الخادم فقط.

```
المتصفح (script.js)  →  خادمك الوسيط (فيه المفتاح)  →  API الذكاء الاصطناعي
```

### ما الذي ينتظره `script.js`؟

الموقع جاهز للربط. يحتاج رابط الخادم فقط:

1. افتح `script.js` واضغط 🔍 وابحث عن `AI_CONFIG`.
2. غيّر `endpoint: ""` إلى رابط خادمك:

```js
var AI_CONFIG = {
  endpoint: "https://your-worker.your-name.workers.dev",
  timeoutMs: 30000
};
```

الموقع يرسل للخادم طلب POST بهذا الشكل:

```json
{ "messages": [ { "role": "user", "content": "مرحبا" } ] }
```

ويتوقع منه رداً بهذا الشكل:

```json
{ "reply": "نص رد المساعد" }
```

إذا بقي `endpoint` فارغاً يعمل الوضع التجريبي المحلي. وإذا فشل الاتصال تظهر رسالة خطأ في المحادثة.

### مثال: خادم وسيط مجاني على Cloudflare Workers

1. أنشئ حساباً على cloudflare.com ثم **Workers & Pages** ثم **Create Worker**.
2. بدّل الكود الافتراضي بهذا:

```js
const ALLOWED_ORIGIN = "*"; // بعد النشر ضع رابط موقعك بدل * (مثال: https://name.github.io)

const CORS = {
  "Access-Control-Allow-Origin": ALLOWED_ORIGIN,
  "Access-Control-Allow-Methods": "POST, OPTIONS",
  "Access-Control-Allow-Headers": "Content-Type"
};

export default {
  async fetch(request, env) {
    if (request.method === "OPTIONS") {
      return new Response(null, { headers: CORS });
    }
    if (request.method !== "POST") {
      return new Response("Method not allowed", { status: 405, headers: CORS });
    }

    let body;
    try { body = await request.json(); }
    catch (e) { return new Response("Bad JSON", { status: 400, headers: CORS }); }

    const messages = (body.messages || []).slice(-20).map(m => ({
      role: m.role === "assistant" ? "assistant" : "user",
      content: String(m.content || "").slice(0, 4000)
    }));
    if (!messages.length) {
      return new Response("No messages", { status: 400, headers: CORS });
    }

    const r = await fetch("https://api.anthropic.com/v1/messages", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "x-api-key": env.ANTHROPIC_API_KEY,
        "anthropic-version": "2023-06-01"
      },
      body: JSON.stringify({
        model: "claude-sonnet-5-5",
        max_tokens: 1000,
        system: "أنت Rafiq، مساعد ودود ومختصر. أجب بلغة المستخدم.",
        messages: messages
      })
    });

    if (!r.ok) {
      return new Response("Upstream error " + r.status, { status: 502, headers: CORS });
    }
    const data = await r.json();
    const reply = (data.content || []).map(c => c.text || "").join("");
    return new Response(JSON.stringify({ reply: reply }), {
      headers: { "Content-Type": "application/json", ...CORS }
    });
  }
};
```

3. من **Settings ثم Variables and Secrets** أضف متغيراً سرياً (Secret) اسمه `ANTHROPIC_API_KEY` وقيمته مفتاحك من console.anthropic.com.
4. انسخ رابط الـ Worker وضعه في `AI_CONFIG.endpoint`.

> اسم النموذج `claude-sonnet-5-5` قد يتغير مع الوقت. راجع docs.claude.com لأحدث الأسماء.

### تنبيهات أمان وتكلفة

- بدّل `ALLOWED_ORIGIN` من `*` إلى رابط موقعك الحقيقي بعد النشر.
- الاستخدام **يُحسب على رصيدك**. هذا الخادم بدون تسجيل دخول حقيقي، فأي شخص يعرف رابطه قد يستهلك رصيدك. ضع حداً أقصى للصرف في لوحة مزوّد الخدمة، وأضف لاحقاً تحققاً من المستخدم وحداً لعدد الطلبات.
- لا تشارك رابط الـ Worker علناً قبل إضافة هذه الحمايات.

## نشر الموقع على الإنترنت

الموقع ملفات ثابتة، فيصلح لأي استضافة مجانية. ارفع `index.html` و`style.css` و`script.js` (و`assets` إن أضفت صوراً):

- **GitHub Pages**: مستودع جديد ثم رفع الملفات ثم Settings ثم Pages.
- **Netlify** أو **Cloudflare Pages**: ارفع المجلد كما هو.

كلها تعمل من متصفح الجوال. بعد النشر:
1. جرّب الموقع من جهاز آخر.
2. تذكّر أن بيانات كل جهاز مستقلة (LocalStorage).
3. لو ربطت الذكاء الاصطناعي، حدّث `ALLOWED_ORIGIN`.
